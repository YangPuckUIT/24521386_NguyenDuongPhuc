# Homework 1 – Interactive Card-Swipe Deck

**Edition:** Hen Ho Nhung Khong Yeu

A full-stack card-swiping application built with React 19, Express, MongoDB, and Mongoose 8.

## Features

- Keyboard and pointer-based swipe interactions.
- Like, Reject, and Super Like actions.
- LIFO undo functionality.
- Derived score calculation.
- REST API integration and MongoDB persistence.

## Project Structure

- `frontend/`: React application.
- `backend/`: Express REST API and database integration.
- `screenshots/`: Project screenshots and testing evidence.
- `TASK_DECOMPOSITION.md`: Development plan and task checklist.
