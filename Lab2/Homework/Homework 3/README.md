# VN Mega Sale 11.11

High-Concurrency Flash-Sale E-Commerce Engine.

## Overview

A Vietnam 11.11 Flash Sale simulation built using Vite and TypeScript.

## Technology Stack

- Vite
- TypeScript
- HTML5
- CSS3
- Browser APIs

## Planned Features

- Anti-drift countdown timer
- Inventory finite state machine
- Temporary stock reservation
- Reservation lock expiration
- Checkout lifecycle
- Concurrent purchase simulation
- AI failure mode audit

## Getting Started

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Build the project:

```bash
npm run build
```
